[1m[33m11.1 What Is a Gem?[0m
[90m-------------------[0m
A gem is a packaged Ruby library. RubyGems is the package manager that
ships with Ruby.

[1m[33m11.2 Installing a Gem[0m
[90m---------------------[0m
[32m    gem install colorize[0m

List what you have installed:

[32m    gem list[0m

[1m[33m11.3 Using a Gem in Code[0m
[90m------------------------[0m
[32m    require "colorize"[0m

[32m    puts "This is red".red[0m
[32m    puts "This is bold".bold[0m

[1m[33m11.4 Bundler[0m
[90m------------[0m
Bundler manages a project's gem dependencies.

Create a Gemfile:

[2m[32m    # Gemfile[0m
[32m    source "https://rubygems.org"[0m
[32m    gem "colorize"[0m
[32m    gem "nokogiri"[0m

Install everything:

[32m    bundle install[0m

Then load the gems:

[32m    require "bundler/setup"[0m
[32m    require "colorize"[0m

[1m[33m11.5 Project Layout[0m
[90m-------------------[0m
[32m    my-project/[0m
[32m    |-- Gemfile[0m
[32m    |-- lib/[0m
[32m    |   `-- my_project.rb[0m
[32m    `-- bin/[0m
[32m        `-- my_project[0m

Add the lib folder to the load path so requires work:

[32m    $LOAD_PATH.unshift(File.expand_path("../lib", __dir__))[0m
[32m    require "my_project"[0m

[1m[33m11.7 Testing with RSpec[0m
[90m-----------------------[0m

[32m    bundle install[0m
[32m    rspec --init[0m
[32m    rspec[0m
