[1m[31mCHAPTER 1 - HELLO WORLD & SETUP[0m
[90m===============================[0m

[1m[33m1.1 Install Ruby[0m
[90m----------------[0m
Debian / Ubuntu:
[32m    sudo apt update[0m
[32m    sudo apt install ruby-full[0m

Verify it worked:
[32m    ruby --version[0m

[1m[33m1.2 Your First Program[0m
[90m----------------------[0m
Create a file named hello.rb:

[32m    puts "Hello, World!"[0m

Run it:

[32m    ruby hello.rb[0m

[1m[33m1.3 The Interactive Shell (IRB)[0m
[90m-------------------------------[0m
Ruby ships with a built-in REPL called irb. Launch it:

[32m    irb[0m

Then type:

[32m    >> 2 + 2[0m
[32m    => 4[0m

[1m[33m1.4 Output Methods[0m
[90m------------------[0m
[32m    puts "hello"     # prints with a trailing newline[0m
[32m    print "hello"    # prints with no newline[0m
[32m    p "hello"        # prints the inspect form: "hello"[0m

That is all you need to start. Move on to chapter 2.
