CHAPTER 5 - CONTROL FLOW
========================

5.1 if / elsif / else
---------------------
    age = 20

    if age >= 18
      puts "Adult"
    elsif age >= 13
      puts "Teen"
    else
      puts "Child"
    end

Note: it is ELSIF, with no second 'e'.

5.2 unless
----------
The opposite of if.

    sunny = false

    unless sunny
      puts "Bring an umbrella"
    end

5.3 Inline Modifiers
--------------------
    puts "Yes" if age >= 18
    puts "No"  unless sunny

5.4 Comparison Operators
------------------------
    ==   equal
    !=   not equal
    >    greater than
    <    less than
    >=   greater or equal
    <=   less or equal
    <=>  spaceship (returns -1, 0, or 1)

Remember: == compares values, .equal? compares object identity.

5.5 Logical Operators
---------------------
    &&   and
    ||   or
    !    not

    if age >= 18 && sunny
      puts "Great day for a walk"
    end

5.6 Case Statement
------------------
    fruit = "apple"

    case fruit
    when "apple"
      puts "Apple pie"
    when "banana"
      puts "Banana bread"
    else
      puts "Unknown fruit"
    end
