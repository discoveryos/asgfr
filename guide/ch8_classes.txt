[1m[31mCHAPTER 8 - CLASSES & OBJECTS[0m
[90m=============================[0m

Imagine you have a cookie cutter: once you design the shape (the class),
you can stamp out as many cookies (objects) as you want. Classes are
blueprints; objects are the real things built from them.

[1m[33m8.1 Defining a Class[0m
[90m--------------------[0m
[32m    class Dog[0m
[32m      def initialize(name)[0m
[32m        @name = name[0m
[32m      end[0m

[32m      def bark[0m
[32m        puts "#{@name} says Woof!"[0m
[32m      end[0m
[32m    end[0m

[32m    my_dog = Dog.new("Rex")[0m
[32m    my_dog.bark[0m

class/.../end defines the blueprint. Dog.new("Rex") creates an actual
dog from it, and @name stores data inside that specific instance.

[1m[33m8.2 The Initializer[0m
[90m-------------------[0m
initialize is the constructor. @name is an instance variable that
belongs to that one object. It runs automatically whenever you call
.new, so it is the perfect place to set up starting values.

[1m[33m8.3 Getters and Setters[0m
[90m-----------------------[0m
[32m    class Dog[0m
[32m      attr_reader :name     # getter only[0m
[32m      attr_writer :name     # setter only[0m
[32m      attr_accessor :age    # both getter and setter[0m

[32m      def initialize(name, age)[0m
[32m        @name = name[0m
[32m        @age = age[0m
[32m      end[0m
[32m    end[0m

[32m    d = Dog.new("Rex", 3)[0m
[32m    puts d.name    # Rex[0m
[32m    d.name = "Max"[0m
[32m    d.age = 4[0m

attr_reader lets you read, attr_writer lets you change, and
attr_accessor gives you both. One line each, tons of boilerplate saved.

[1m[33m8.4 Class Methods (self.)[0m
[90m-------------------------[0m
Called on the class itself, not an instance.

[32m    class Dog[0m
[32m      def self.species[0m
[32m        "Canis familiaris"[0m
[32m      end[0m
[32m    end[0m

[32m    puts Dog.species[0m

Instance methods describe what one object can do. Class methods
describe what the whole group knows -- like a fun fact shared
by every Dog.

[1m[33m8.5 Class Variables (@@)[0m
[90m------------------------[0m
Shared across every instance.

[32m    class Dog[0m
[32m      @@count = 0[0m

[32m      def initialize[0m
[32m        @@count += 1[0m
[32m      end[0m

[32m      def self.count[0m
[32m        @@count[0m
[32m      end[0m
[32m    end[0m

[32m    Dog.new[0m
[32m    Dog.new[0m
[32m    puts Dog.count    # => 2[0m

@@variables are like a shared tally sheet. Every new Dog marks it,
and Dog.count tells you the total so far.

[1m[33m8.6 Inheritance[0m
[90m---------------[0m
[32m    class Animal[0m
[32m      def speak[0m
[32m        puts "Some sound"[0m
[32m      end[0m
[32m    end[0m

[32m    class Cat < Animal[0m
[32m      def speak[0m
[32m        puts "Meow"[0m
[32m      end[0m
[32m    end[0m

[32m    Cat.new.speak    # => Meow[0m

Inheritance means Cat gets everything Animal can do for free, and
then overrides only what is different. Think of it as customizing
a family recipe while keeping the basics.
