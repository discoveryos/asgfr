1. WHAT YOU NOW KNOW
[90m--------------------[0m
Take a moment: you can write scripts, build classes, handle files and
errors, use regex, work with arrays and hashes functionally, connect
to web APIs, build websites, test your code, and even ship your own

2. BUILD SOMETHING REAL
[90m-----------------------[0m
The fastest way to improve is to make something you care about. Pick
one and finish it:
[32m    - a personal budget tracker (stores transactions in a file)[0m
[32m    - a weather app (fetch an API, ch21)[0m
[32m    - a to-do app with a web UI (Sinatra or Rails)[0m
[32m    - a small 2D game (Gosu / Mittsu, ch14)[0m
[32m    - a CLI tool that renames or organizes files[0m
[32m    - a gem that solves one thing well (ch15)[0m

A finished small project teaches more than ten half-read tutorials.

3. READ OTHERS' CODE
[90m--------------------[0m
Reading real Ruby is how you absorb idioms and patterns quickly.
[32m    - browse popular gems on GitHub (rspec, sinatra, httparty)[0m
[32m    - run pry on code you find interesting[0m
[32m    - use irb to test things you do not understand[0m

5. CONTRIBUTE TO OPEN SOURCE
[90m----------------------------[0m
Contributing looks great and teaches you a lot.
[32m    1. find a gem you use on GitHub[0m
[32m    2. look at issues labelled "good first issue"[0m
[32m    3. fork, fix, and open a pull request[0m
[32m    4. read the contribution guide and tests first[0m

Even a typo fix or an added test counts. Start small.

6. DO A SMALL PROBLEM A DAY
[90m---------------------------[0m
Keep coding regularly with short exercises:
[32m    - Project Euler[0m
[32m    - Exercism (great Ruby track with mentorship)[0m
[32m    - Codewars katas[0m
[32m    - Advent of Code every December[0m

Fifteen focused minutes a day beats six hours once a month.

7. PENNY PRACTICE: INTERVIEW QUESTIONS
[90m--------------------------------------[0m
If jobs are a goal, practise the classics in Ruby:
[32m    - reverse a string without .reverse[0m
[32m    - find the most frequent word in a text[0m
[32m    - implement FizzBuzz (ch12)[0m
[32m    - write a recursive Fibonacci[0m
[32m    - check if a string is a palindrome[0m

[32m    def palindrome?(s)[0m
[32m      clean = s.downcase.gsub(/[^a-z0-9]/, "")[0m
[32m      clean == clean.reverse[0m
[32m    end[0m

[32m    puts palindrome?("A man a plan a canal Panama")   # => true[0m

9. THE RUBY PHILOSOPHY
[90m----------------------[0m
"Matz is nice and so we are nice." Ruby was designed to be a joy to
use. As you grow, you will learn not just syntax but taste: readable,
expressive, humane code. Aim for code that other humans (and future
you) enjoy reading.
